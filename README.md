## 🚀 Futuristic 3D & Glassmorphic UI Redesign

### 1. Cyber-Space Glassmorphism Aesthetic

* **Frosted Glass Surfaces**: Translucent UI panels built with `backdrop-filter: blur(16px) saturate(180%)`, deep obsidian-blue glass backgrounds, and glowing neon-cyan / gold edge reflections.

* **Atmospheric Background**: Deep cosmic cyber grid with animated floating radial gradient orbs that move subtly in the background.

* **3D Card Depth & Elevation**: Cards and interactive elements feature perspective depth (`perspective: 1000px`), rising with smooth 3D tilt and glowing neon drop shadows when hovered.

### 2. Smooth 3D Opening & Transition Animations

* **3D Tab Switching Animation (`tabEnter3D`)**: Switching between tabs smoothly slides and rotates content forward along the 3D X-axis with perspective scaling.

* **3D Glass Modal Pop-In (`glassModal3D`)**: Modals (Add Student, Student Profile, Settings) open with a smooth 3D zoom, perspective tilt, and backdrop blur bloom.

* **Biometric Card Spring-In (`popCardIn`)**: Verified student dossier cards spring into view with green/cyan cybernetic edge flares.

### 3. Holographic 3D Biometric Scanner HUD

* **Rotating Holographic Target Ring**: Animated multi-ring biometric target with smooth 360-degree rotation.

* **Quantum Laser Blade**: Dual-color neon laser sweep (cyan to gold) scanning up and down the video frame.

* **Telemetry Readout**: Live diagnostic indicators (`[ 3D LANDMARK MESH: LOCKED ]`, `[ AI NEURAL ENGINE: READY ]`, `[ LIVENESS SENSOR: ONLINE ]`).

* **Corner Tech Brackets**: Glowing cyan holographic brackets anchoring the face detection zone.

### 4. Interactive 3D Period Pills & Controls

* **Capsule Period Badges**: Styled like glowing sci-fi capsules. Active periods glow with intense cyan-gold laser illumination.

* **Click to Inspect**: Click any period badge to instantly view its Present and Absent student rosters.

* **Mobile Camera Flip (`🔄 Flip Camera`)**: Easily toggle between front and rear cameras on mobile phones and tablets.

## 🛠️ Biometric & Security Engine

* **Face Presence Detection (`detectFacePresence`)**: Evaluates skin chrominance density and texture variance, rejecting empty rooms, blank walls, ceilings, and desks (`❌ NO FACE DETECTED!`).

* **Anti-Spoofing & Liveness Protection**: Multi-frame micro-motion verification rejects static photos and mobile phone screens.

* **Zero-Normalized Cross Correlation (ZNCC)**: High-accuracy facial feature matching prevents false matches between different students.

* **Anti-Proxy Duplicate Detection**: Scanning the same student face twice in the same period alerts `⚠️ FACE ALREADY SCANNED!`.
